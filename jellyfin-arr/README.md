# Jellyfin + *arr stack

A Docker Compose media stack with Jellyfin, Sonarr, Radarr, Prowlarr, Bazarr,
Jellyseerr, and qBittorrent. It is intended for a Linux host running Docker
Compose.

## Start

1. Copy `.env.example` to `.env` and set `PUID`, `PGID`, and `TZ` for your host.
2. Create the media folders under `DATA_ROOT` (defaults to `./data`):

   ```text
   data/
   ├── downloads/
   ├── movies/
   └── tv/
   ```

3. Ensure the configured user (`PUID:PGID`) can write to `CONFIG_ROOT` and
   `DATA_ROOT`.
4. From this directory, start the services:

   ```sh
   docker compose up -d
   ```

Compose creates configuration directories as needed. To stop the stack, run
`docker compose down`; media and configuration remain on disk.

## Web interfaces

| Service | Default URL |
| --- | --- |
| Jellyfin | <http://localhost:8096> |
| Sonarr | <http://localhost:8989> |
| Radarr | <http://localhost:7878> |
| Prowlarr | <http://localhost:9696> |
| Bazarr | <http://localhost:6767> |
| Jellyseerr | <http://localhost:5055> |
| qBittorrent | <http://localhost:8080> |

Ports can be changed in `.env`. The published ports listen on the host's
interfaces; restrict access with your firewall and do not expose the
administration interfaces directly to the public internet. Use a properly
secured reverse proxy or VPN for remote access.

## Initial configuration

- Create the Jellyfin libraries using `/data/movies` and `/data/tv`.
- In Sonarr and Radarr, add `/data/tv` and `/data/movies` as their respective
  root folders, and use `/data/downloads` for the qBittorrent download path.
- Add qBittorrent as the download client in Sonarr and Radarr. The containers
  share the same `/data` paths to avoid remote path mappings.
- Add indexers in Prowlarr and connect the Sonarr and Radarr apps there.
- Configure Bazarr with the Sonarr and Radarr connections and their `/data`
  root folders.
- Complete Jellyseerr's setup wizard and connect it to Jellyfin and the
  appropriate Radarr and Sonarr instances.

Services on the Compose network can reach each other by service name (for
example, `http://jellyfin:8096`, `http://sonarr:8989`, and
`http://qbittorrent:8080`).

qBittorrent's initial Web UI credentials are generated by the LinuxServer
container and reported in its logs. Retrieve them with
`docker compose logs qbittorrent`, then change the password in qBittorrent.
